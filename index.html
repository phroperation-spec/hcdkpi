Admin Access

Incorrect passcode.
Admin access lets you add entries or import Excel/CSV files. Everyone else can browse, filter, and print only.

Change Admin Passcode

This changes the passcode stored in this browser. If other supervisors unlock admin mode from a different device or browser, share the new passcode with them separately.

Leader Access

Incorrect passcode.
Leader Access is separate from Admin — it lets you view the 🎖 Leadership Targets an admin has set up for your scope (and rate yourself on them, same as any target). It doesn't let you add, import, or edit anything — only an admin can do that.

Change Leader Passcode

This is the passcode leaders use to unlock "🎖 Leader Access" — separate from the Admin passcode. Share the new one with your leaders directly; it syncs to every device automatically.

Manage Directory

This list controls what shows up in the Business Affiliate, Unit, and Functional Group filters. Renaming here also updates matching entries automatically; deleting only removes the option from this list — existing entries keep their values.

Employee Directory

Upload the list of employees once, mapped to the Business Affiliate / Unit / Functional Group they belong to. After that, anyone viewing this page just picks the employee's name — their targets populate automatically, no need to also pick the affiliate, unit, or functional group. Expected columns, first row = headers, first sheet only for Excel files:
Employee Name, Business Affiliate, Business Unit, Functional Group, Leader (Yes/No)
The Affiliate / Unit / Functional Group names should match what's set up in Manage Directory — any that don't exist yet are created automatically. The last column is optional — mark "Yes" to tag someone as a leader (shown as a 🎖 badge below); leaders only need Business Affiliate + Business Unit, so their Functional Group column can be left blank. Leadership Targets themselves are set per-entry via the 🎖 Leadership Target checkbox in Add/Import Entry, and only show in Admin mode or Leader Access.
